# Agenda ejecutiva para Eventos

**Fecha:** 11/09/2026  
**Decisión:** adoptar la propuesta A como vista principal del módulo Eventos.

## Qué queda fijado

1. El calendario mensual es la pieza principal y la lista de próximos eventos funciona como apoyo lateral.
2. El color identifica el área organizadora; nunca se usa para comunicar el estado de preparación.
3. Cada color lleva siempre una sigla visible (`AMB`, `CAH`, `OBR`, `SAL`, `SEG`, `TYP`, `COR`, `SGR` o `—`) para que la lectura no dependa sólo del color.
4. La preparación se expresa con cantidades y texto: confirmados sobre total o “Sin cargar”.
5. La alerta de preparación pendiente aparece junto a la agenda y enlaza al checklist.
6. La identidad institucional general conserva los tokens navy y naranja; los colores categóricos quedan reservados para las áreas.

## Motivo

La pantalla se usa para anticipar qué sucede, cuándo y qué falta resolver. La combinación de calendario, agenda próxima y estado de preparación permite responder esas tres preguntas sin cambiar de pestaña.
